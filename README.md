# my-first-web-project

A simple YouTube-like homepage built with only HTML and CSS, made for beginners.

## Files

- **index.html** — the page structure/content (header, sidebar, video grid).
- **style.css** — all the styling (colors, layout, spacing).

## How it's organized

1. **Header** — top bar with a logo, search box, and a profile icon. Built with Flexbox split into a left/middle/right section.
2. **Sidebar** — the left-hand navigation list (Home, Trending, etc.), a simple `<ul>` list.
3. **Content** — filter "chips" (All, Music, Gaming...) plus a **grid** of video cards. Each video card has a thumbnail placeholder, a round channel icon, a title, and view/upload info.
4. **Responsive** — on small screens (phones), the sidebar hides itself using a CSS media query so the video grid gets more room.

## How to view it

Just open `index.html` in any web browser — no build tools or server needed.
